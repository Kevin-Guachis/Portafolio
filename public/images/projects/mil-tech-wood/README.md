# Capturas de Mil Tech Wood

Imagen principal del resumen: `hero.png`.

El carrusel utiliza únicamente estas dos capturas, en este orden:

1. `catalogo.png`: vista principal del catálogo y tarjetas de productos.
2. `detalle-producto.png`: vista de detalle de un producto.

Las rutas están configuradas en `src/data/projects/mil-tech-wood.js`. Se conservan las proporciones y la ampliación en otra pestaña. Si falta una captura, se muestra un placeholder; no crear imágenes ficticias ni archivos PNG vacíos.

Repositorio indicado por el propietario: https://github.com/Kevin-Guachis/mil-tech-wood-catalogo.
